# API-first ASR migration (Step 1)

Production defaults to `ASR_MODE=api`: Groq `whisper-large-v3` is primary and Cloudflare Workers AI `@cf/openai/whisper-large-v3-turbo` is used only after a retryable Groq provider failure (timeout, 429, or 5xx). Malformed requests and permanent 4xx responses never trigger fallback. Groq retries at most twice with exponential backoff, jitter, and `Retry-After`; a rate-limited Groq key may move to the next configured server-only key slot.

Required private worker variables are `GROQ_API_KEYS` (or numbered `GROQ_API_KEY_*` slots), `CLOUDFLARE_ACCOUNT_ID`, and `CLOUDFLARE_API_TOKEN`. They must never be committed or exposed to the browser. The worker emits only sanitized provider/model/status-class/retry/fallback metrics.

FFmpeg still extracts losslessly compressed 16 kHz mono FLAC locally. If it exceeds the configured upload limit, ClipKaro splits it into chronological FLAC chunks with a two-second overlap, keeps offsets, removes overlap duplicates during reassembly, and enforces an explicit chunk-count ceiling. It never silently truncates creator audio. Provider timestamps pass through ClipKaro's existing hallucination, noise, quality, timestamp-stabilization, provenance, Hindi Roman-display, and export gates. Hindi/Urdu auto ambiguity still prefers Hindi under the India bias; Marathi is never forced to Hindi; Hinglish remains auto-detected and only gets a Roman display transformation after recognition.

`ASR_MODE=local` retains faster-whisper and optional WhisperX for the legacy/qualification worker. API mode never imports or initializes faster-whisper, Torch, or WhisperX. API ASR is **NOT** considered quality-certified for Hindi, Marathi, or Hinglish until the existing frozen real-ASR qualification runs and passes; threshold contract remains unchanged.

Provider assumptions were verified against the official Groq Speech-to-Text documentation and Cloudflare Workers AI model documentation on 2026-08-12. Groq uses multipart `POST /openai/v1/audio/transcriptions`, `Authorization: Bearer`, `verbose_json`, and word+segment timestamp granularities. It supports multilingual `whisper-large-v3`, and lists 25 MB free / 100 MB dev direct-upload limits. Cloudflare is called through the account Workers AI `/ai/run/{model}` API with bearer auth; its official model schema documents text, segments/VTT, language controls, and hallucination/VAD parameters. Cloudflare word timestamps must be returned by the provider response for verified caption export; otherwise the job fails closed.
